# LinkedIn AI Outreach Generator

A Chrome extension that helps generate personalized outreach messages for LinkedIn profiles.

## Features

- Automatically extracts profile information from LinkedIn pages
- Generates messages in 4 different styles (Professional, Friendly, Direct, Enthusiastic)
- Customizable with keywords to include in the message
- Character-limited messages suitable for LinkedIn

## Installation

1. Download or clone this repository
2. Open Chrome and go to `chrome://extensions/`
3. Enable "Developer mode" in the top right corner
4. Click "Load unpacked" and select the `linkedin-ai-outreach` folder
5. The extension icon should appear in your Chrome toolbar

## Usage

1. Navigate to any LinkedIn profile page
2. Click the extension icon in your Chrome toolbar
3. Enter keywords you want to include in the message (separated by commas)
4. Select your preferred message style
5. Click "Generate Message"
6. Copy the generated message and use it in your LinkedIn outreach

## Message Styles

- **Professional**: Formal and business-appropriate
- **Friendly**: Casual and approachable
- **Direct**: Straightforward and to the point
- **Enthusiastic**: Energetic and engaging

## Note

Remember to replace `[Your Name]` in the generated messages with your actual name before sending.
